Программный модуль фитнес-трекера "Step-by-Step" на Go 

Высокоуровневый программный модуль на языке **Go** для фитнес-трекера от компании *Champion*. Приложение принимает сырые текстовые данные от датчиков устройства, валидирует их, сопоставляет с метриками пользователя и рассчитывает спортивные показатели: пройденную дистанцию, среднюю скорость и сожженные калории для разных видов активности.

##  Эволюция архитектуры проекта
Проект прошел путь от процедурного стиля к продвинутому объектно-ориентированному проектированию (ООП):
1. **Первая итерация (Базовая):** Была реализована базовая процедурная логика, парсинг сырых строк (`strings`, `strconv.Atoi`), работа с `time.Duration` и расчет калорий через функции в независимых пакетах.
2. **Вторая итерация (Финальная):** Код полностью переписан на структуры, методы и интерфейсы. Проведена глубокая декомпозиция на **5 специализированных пакетов**, связанных между собой через композицию и полиморфизм.

## Архитектура и структура пакетов

Логика приложения строго разделена по зонам ответственности:

### 1. `package personaldata` (Персональные данные)
*   Определяет структуру для хранения антропометрических данных пользователя: имя, вес, рост.
*   Содержит методы для вывода персональных данных на экран.

### 2. `package spentenergy` (Расчет энергозатрат)
*   Ядро математических вычислений модуля.
*   Отвечает за расчет средней скорости движения, пройденного расстояния и калорий, сожженных при беге или ходьбе.

### 3. `package trainings` (Спортивные тренировки)
*   Определяет структуру тренировки (шаги, длительность, тип активности).
*   Использует **встраивание структур (embedding)**: в структуру тренировки встроены персональные данные для быстрого доступа к весу и росту.
*   Реализует методы парсинга тренировочной строки (например, `"3456,Бег,0h45m"`) и генерации детального отчета.

### 4. `package daysteps` (Ежедневная активность)
*   Отвечает за учет повседневных прогулок и шагов за день вне тренировок (пакетные данные вида `"678,0h50m"`).
*   Имеет схожую с `trainings` структуру методов, что позволяет применять к ним единый интерфейс.

### 5. `package actioninfo` (Интерфейсный полиморфизм)
*   **Главная фишка архитектуры.** Здесь объявлен интерфейс, объединяющий методы парсинга и формирования отчетов для пакетов `trainings` и `daysteps`.
*   Содержит универсальную функцию, принимающую интерфейс как аргумент. Программа динамически определяет, какая структура (тренировка или прогулка) передана, и вызывает её собственные методы ("Duck Typing").

##  Ключевые технологии и фишки Go в проекте

*   **Композиция вместо наследования:** Расширение структур данных с помощью идиоматичного для Go механизма эмбеддинга (встраивания).
*   **Полиморфизм через интерфейсы:** Реализация гибкой архитектуры, готовой к добавлению новых видов активности (например, плавания) без изменения кода интерфейсного пакета.
*   **Безопасная обработка данных:** Строгая валидация входящих параметров (защита от деления на ноль, проверка на отрицательные шаги) и идиоматичный возврат ошибок (`error`).
*   **Парсинг и приведение типов:** Работа со стандартными пакетами `strings`, `strconv` и парсинг кастомных временных интервалов через `time.ParseDuration`.

## ⚙️ Инструкция по запуску

Для запуска проекта локально убедитесь, что у вас установлен [Go](https://go.dev).

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Перейдите в папку с проектом:
   ```bash
   cd название_папки_проекта
   ```
3. Запустите программу:
   ```bash
   go run main.go
   ```
